🛠️ Архитектура CI/CD пайплайна

Наша система построена на базе облачных раннеров GitHub. При каждом изменении исходного кода (команда git push) запускается сценарий сборки, который проверяет файлы и публикует их в интернете через GitHub Pages. 🌐

Компонент Назначение
📂 index.html / about.html Интерфейс пользователя и контент сайта
🎨 style.css Современное адаптивное оформление на всю ширину
⚙️ deploy.yml Скрипт автоматического деплоя в GitHub Actions
